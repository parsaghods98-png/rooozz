# روزنگار — راهنمای ساخت با گوشی

۱. در github.com حساب بساز و یک مخزن جدید با نام rooznegar و حالت Public بساز.
۲. زیپ را روی گوشی باز کن (Extract). در مخزن: Add file ← Upload files و همه‌ی فایل‌ها را انتخاب کن ← Commit changes.
۳. Add file ← Create new file. در کادر نام بنویس: .github/workflows/build.yml  و محتوای فایل workflow-build.yml را کپی و Paste کن ← Commit.
۴. اندروید: تب Actions ← Build ← بعد از پایان (حدود ۵ تا ۱۰ دقیقه) داخل اجرا، پایین صفحه Artifacts ← rooznegar-apk را دانلود کن، از زیپ دربیار و نصب کن (اجازه‌ی نصب از منبع ناشناس لازم است).
۵. آیفون یا نسخه‌ی وب: Settings ← Pages ← Source را روی GitHub Actions بگذار و Build را دوباره اجرا کن. آدرس https://نام-کاربری.github.io/rooznegar/ را در مرورگر باز کن ← Share ← Add to Home Screen.

نکته: دستیار هوشمند و ساخت برنامه‌ی روزانه از روی توضیح فقط داخل کلود کار می‌کنند. برنامه‌ی ورزشی در نسخه‌ی نصبی با حرکت‌های آماده و کلمات توضیحت ساخته می‌شود. بقیه‌ی بخش‌ها آفلاین‌اند و اطلاعات روی گوشی ذخیره می‌شود.
